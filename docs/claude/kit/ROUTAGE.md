# Routage : le point concerne… → session
| Le point concerne… | Session |
|---|---|
| menu, en-tête, couleurs, alignement, écart avec une maquette, ergonomie | Admin |
| Aujourd'hui, Caisse (affichage), Réglages, Enseigne | Admin |
| boutique, QR, coordonnées, panier, rubrique fêtes | Client |
| commande, retrait, statut, stock vendu | Commandes |
| production, fournée, coût, prix, marge, CA, tableau de bord, produits, coffrets, stock, matières | Gestion |
| clients existants, consentement, offres, annonce, Publimail, promos, automatisation | Croissance (Communication) |
| prospection : nouveaux clients, cibles, séquences, contenus numériques | Prospection |
| tout le reste, ou on ne sait pas | Entrée |

Règles : un point = une seule session. S'il touche plusieurs zones, il va dans la rubrique qui possède le code partagé, avec « voir aussi ». Sans réponse claire : « à classer » avec la question. L'Entrée classe, écrit, indique ; elle ne corrige rien.
Exemples : le menu latéral ne s'aligne pas → Admin. Une commande remise ne baisse pas le stock → Commandes (voir aussi Gestion). « Je veux relancer les clients de la pissaladière » → à classer (Croissance ou Gestion).

## Test à blanc (25/11/2026)
1. Défaut dans un seul profil : « le bouton Encaisser est coupé sur mon téléphone » → Admin.
2. Défaut qui en touche plusieurs : « une commande retirée n'a pas baissé le stock et le CA est faux » → Commandes (circuit) ; voir aussi Gestion (définition du CA).
3. Défaut sans réponse claire : « les clients ne reçoivent pas l'annonce de la nouvelle fournée » → à classer : Croissance (diffusion) ou Gestion (validation de fournée) ; l'Entrée pose la question « le message est-il généré ou envoyé ? ».
